# Kombucha E-Commerce 🫙

Современный интернет-магазин крафтовой комбучи с удобным интерфейсом и безопасным процессом оплаты. Проект построен на Vanilla JS и Vite, полностью интегрирован со Stripe Checkout и работает на базе бессерверных функций Vercel.

## Особенности проекта

* **Динамичный интерфейс:** Интерактивный каталог товаров и боковая корзина (off-canvas), сохраняющая состояние через `localStorage`.
* **Безопасные платежи:** Интеграция Stripe Checkout (полное соответствие PCI-DSS). Данные банковских карт не проходят через серверную или клиентскую часть кода.
* **Serverless Архитектура:** API-роуты Vercel (`api/`) безопасно создают платежные сессии и верифицируют вебхуки.
* **Защищенная логика заказов:** Успешность оплаты проверяется исключительно через серверные вебхуки Stripe, исключая возможность подмены данных на клиенте.

## Технологии

* **Фронтенд:** Нативный JavaScript (ES modules, без тяжелых фреймворков), HTML5, CSS3.
* **Сборка:** Vite 6.
* **Бэкенд:** Vercel Serverless Functions (Node.js).
* **Платежный шлюз:** Stripe Checkout API и Webhooks.

## Как запустить локально

*Примечание: Для корректной работы бессерверных функций (`/api`) необходимо использовать Vercel CLI, а не стандартный запуск Vite.*

1. Склонируйте репозиторий и установите зависимости: `npm install`
2. Зарегистрируйтесь в Stripe и получите тестовые API-ключи.
3. Скопируйте файл `.env.example` в `.env` и добавьте ваш `STRIPE_SECRET_KEY`.
4. Запустите локальный сервер: `vercel dev` (запускает фронтенд и API на порту 3000).

## Деплой и релиз

Деплой выполняется автоматически через интеграцию Vercel с GitHub. Для запуска в production:
1. Добавьте **боевые (Live)** ключи Stripe в переменные окружения Vercel.
2. Настройте production-вебхук в панели Stripe (`checkout.session.completed`) и добавьте полученный секрет в переменную `STRIPE_WEBHOOK_SECRET`.
